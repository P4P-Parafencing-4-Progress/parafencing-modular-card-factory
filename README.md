## 1. Executive Summary & Mission

Wheelchair fencing coach education faces a fundamental challenge: **over 85% of wheelchair fencers train in local, able-bodied fencing clubs** where a certified para-fencing master is rarely present daily. Club personal coaches and able-bodied sparring partners (*partenaires valides*) want to support their seated athletes, but they often lack standardized rigging protocols, clear safety boundaries, and structured tactical progressions.

The **Parafencing Modular Lesson Card Factory** bridges this gap:
* It transforms complex sports science and Paralympic coaching methodology into standardized, double-sided **5x7 inch operational cards**.
* It provides floor coaches with crisp, zero-fluff drill sequences on **Side A**, while equipping home coaches, able-bodied training partners, and athletes with practical translation guides and self-audits on **Side B**.
* Rather than remaining an ad-hoc set of drills, it serves as the foundational building-block engine for an accredited **USFCA Para-Fencing Coaching Curriculum**, directly supporting the active development of the **Level 4 (Prévôt / Bravo)** coach certification.

## 2. The Dual-Track Card Architecture

Each modular card is an invariant, double-sided 5x7 inch coaching unit designed to function in two distinct operational environments:

```
+-----------------------------------------------------------------------------------+
|                        SIDE A: STRIP-SIDE FIELD AID                               |
|                  (For Floor Coaches at Camps & Group Practices)                   |
|                                                                                   |
|  * Universal Metadata: Module Code, USFCA Level, Weapon, Time Station, Category  |
|  * Micro-Objective: Measurable behavioral outcome                                 |
|  * Biomechanical Geometry: Exact angles, measure points, and grip tensions        |
|  * 3-Phase Station Ladder: Step 1 (Setup) -> Step 2 (Reach) -> Step 3 (Scenario)  |
|  * Red-Flag Faults vs. Optimal Mechanics                                          |
|  * Kinesthetic Feel: High-information cue ("Economie de mots")                    |
+-----------------------------------------------------------------------------------+
                                         |
                       [ TURN CARD OVER TRACKSIDE ]
                                         v
+-----------------------------------------------------------------------------------+
|                     SIDE B: HOME-CLUB TRANSLATION & AUDIT                         |
|            (For Personal Coaches, Able-Bodied Sparring Partners & Athletes)        |
|                                                                                   |
|  * Home-Club Setup: How to run the drill without a metal frame (Stationary Chair) |
|  * Partner Protocol: Safe, realistic cueing instructions for able-bodied fencers |
|  * Compensatory Symmetry: Corrective physical exercises (Lesgaft protocol)        |
|  * Coach Observation Cues: Tactile and visual watchpoints                         |
|  * Closed-Loop Athlete Self-Audit: 3-point kinesthetic verification (YES / NO)    |
+-----------------------------------------------------------------------------------+
```

## 5. Transferability to Standing Fencing

A major pedagogical strength of this system is its **bilateral value for standing fencing**:
* **Accelerated Infighting & Hand Speed**: Because wheelchair fencers cannot rely on retreating footwork, their hand-speed, line perception, and close-quarters parry-ripostes develop at twice the rate of traditional fencers.
* **Core Stability & Scapular Control**: Seated non-weapon arm kinetic coupling translates directly to improved trunk stability and point control for standing foil, épée, and sabre fencers.
* **Inclusive Club Culture**: Standing fencers who sit in a stationary chair to drill with a wheelchair teammate develop refined blade sensitivity while integrating the entire club roster.
